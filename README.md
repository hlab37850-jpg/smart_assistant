# المساعد الذكي — Smart Assistant

مشروع Flutter Android فعلي، بواجهة عربية RTL مستوحاة من الصورة المرجعية.

الوظائف المضمنة: SQLite، العملاء، الأصناف والمخزون، الاستحقاقات، الإحصاءات، التقارير، PDF، استيراد CSV/XLSX، النسخ الاحتياطي JSON، ومساعد AI عبر API متوافق مع OpenAI/OpenRouter.

بعد رفع الملفات إلى GitHub سيبدأ Workflow تلقائياً على push إلى main/master، أو يمكن تشغيله يدوياً من Actions.

لا تضع API Key داخل المستودع.
